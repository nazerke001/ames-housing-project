# Ames Housing Prediction

Predicting residential home prices in Ames, Iowa, using machine learning and exploratory data analysis.

#Project overview:
This project focuses on analyzing housing data from Ames, Iowa, and building regression models to accurately estimate home values.The goal is to identify the key features that affect house prices.

##Data set information
**Source**:Ames Housing Data Set
**Observations**:2930 properties
**Features**:80+ categorical and numerical variables describing quality, location, condition, and square footage.
**Target Variable:** 'Sale Price' (Continuous)

##Pipeline
1. **Data Cleaning**: Handled missing values, treated outliers, and processed categorical features.
2. **Exploratory Data Analysis**: Analyzed feature distributions and correlations with the target variable 'Sale Price'.
3. **Model Training & Evaluation:** Trained and evaluated multiple regression algorithms using metrics such as RMSE and R² score.
